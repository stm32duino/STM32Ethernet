◆ stm32_eth_init()

void stm32_eth_init ( const uint8_t *  mac,
const uint8_t *  ip,
const uint8_t *  gw,
const uint8_t *  netmask 
)

Initialize the Ethernet interface and the LwIP stack.

LwIP initialization and the scheduler timer setup run only on the first call. Every call reconfigures the network interface and runs one scheduler pass.

A NULL argument selects the default value:

  • mac: the MAC address is left unchanged.
  • ip, gw, netmask: set to zero when LWIP_DHCP is enabled, otherwise to the compile-time defaults (IP_ADDR*, GW_ADDR*, NETMASK_ADDR*).
Parameters
macMAC address (6 bytes), or NULL to keep the default MAC address.
ipIPv4 address (4 bytes), or NULL for the default.
gwGateway address (4 bytes), or NULL for the default.
netmaskNetmask (4 bytes), or NULL for the default.

struct pbuf * stm32_new_data ( struct pbuf *  p,
const uint8_t *  buffer,
size_t  size 
)

Allocate a pbuf holding the given data.

If p is NULL, allocates a new pbuf and copies buffer into it. Otherwise, allocates a larger pbuf, copies the contents of p and appends buffer, then frees p. On failure, returns NULL and leaves p unchanged.

Parameters
pExisting pbuf to extend, or NULL to create a new one.
bufferData to store.
sizeNumber of bytes to store from buffer.
Returns
Pointer to the pbuf holding the data, or NULL on failure.
