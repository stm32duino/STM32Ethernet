int EthernetClass::begin ( uint8_t *  mac_address,
unsigned long  timeout = 60000,
unsigned long  responseTimeout = 4000 
)

Initialises Ethernet with the given MAC address and gets the network configuration from a DHCP server.

The MAC address is only applied if the interface is not yet initialised. Blocks until a lease is obtained or the timeout expires. On success the DNS server is taken from DHCP.

Parameters
mac_addressSix-byte MAC address to use.
timeoutMaximum time to wait for the DHCP lease, in milliseconds.
responseTimeoutUnused; kept for compatibility.
Returns
1 if the DHCP configuration succeeded, 0 if it failed.

◆ maintain()

int EthernetClass::maintain ( )

Checks the DHCP lease and reports the result of a renew or rebind.

Does nothing and returns DHCP_CHECK_NONE if DHCP was never started. When a renew or rebind succeeds, the DNS server is updated from DHCP.

Returns
DHCP_CHECK_NONE (0) if nothing happened, DHCP_CHECK_RENEW_FAIL (1), DHCP_CHECK_RENEW_OK (2), DHCP_CHECK_REBIND_FAIL (3) or DHCP_CHECK_REBIND_OK (4).

◆ schedule()

void EthernetClass::schedule ( void  )

Services the LwIP stack.

Triggers the stack scheduler, which handles packet input, the link check, timeouts and DHCP processing. Useful in long loops where the stack would otherwise not be updated.
