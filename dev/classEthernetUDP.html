uint8_t EthernetUDP::begin ( IPAddress  ip,
uint16_t  port,
bool  multicast = false 
)
virtual

Opens a UDP socket bound to a local address and port.

Fails if this object already has an open socket. When multicast is true, the socket binds to any address and joins the multicast group ip through IGMP (when LWIP_IGMP is enabled). Otherwise it binds to ip. If the bind fails, the socket is closed. If the IGMP join fails, the socket stays open; call stop() to close it.

Parameters
ipLocal address to bind to, or the multicast group to join.
portLocal port to listen on.
multicasttrue to join the multicast group ip, false for a unicast socket bound to ip.
Returns
1 on success. 0 if a socket is already open, if the UDP PCB cannot be created or bound, or if the IGMP join fails.

Sets the destination for the next outgoing packet by host name.

Resolves host with a DNS query to the server returned by Ethernet.dnsServerIP(), then calls beginPacket(IPAddress, uint16_t).

Parameters
hostHost name, or a numeric address string.
portDestination port.
Returns
1 on success. If the lookup does not succeed, the negative DNS error code from DNSClient::getHostByName(). Otherwise the result of beginPacket(IPAddress, uint16_t).

◆ parsePacket()

int EthernetUDP::parsePacket ( )
virtual

Advances to the next received packet.

Runs the Ethernet scheduler. If a datagram is queued, records its sender for remoteIP() and remotePort() and its unread size for available() and read().

Returns
Size of the queued packet in bytes, or 0 if none is queued.
