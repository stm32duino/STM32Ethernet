int DhcpClass::beginWithDHCP ( uint8_t *  mac,
unsigned long  timeout = 60000,
unsigned long  responseTimeout = 4000 
)

Starts a DHCP lease request.

Blocks until a lease is obtained or the timeout expires.

Parameters
macSix-byte MAC address to use. If NULL, the MAC address of the Ethernet interface is used.
timeoutMaximum time to wait for the lease, in milliseconds.
responseTimeoutUnused; kept for compatibility.
Returns
1 if the lease was granted, 0 otherwise.

◆ checkLease()

int DhcpClass::checkLease ( )

Checks the DHCP lease for a renew or rebind result.

Runs the Ethernet scheduler on each call. Applications normally call it through Ethernet.maintain(), which should be run regularly.

Returns
DHCP_CHECK_NONE (0) if nothing happened, DHCP_CHECK_RENEW_FAIL (1), DHCP_CHECK_RENEW_OK (2), DHCP_CHECK_REBIND_FAIL (3) or DHCP_CHECK_REBIND_OK (4).
