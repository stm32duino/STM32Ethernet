uint8_t EthernetClient::getSocketNumber ( )

Returns the socket number, for W5100 compatibility.

This function is specific to the W5100 architecture and is not defined by Arduino. It is kept for compatibility and always returns 0 because this implementation has no socket numbers.

Always 0.

bool EthernetClient::operator== ( const EthernetClient &  rhs)
virtual

Tests whether two clients refer to the same connection.

Two clients with no connection structure compare equal, and the function then reads a NULL pointer. Only compare clients that have a connection.

Parameters
rhsClient to compare with.
Returns
true if both clients use the same connection structure and the same TCP control block, false otherwise.

void EthernetClient::stop ( )

Closes the connection and releases the client structure.

The connection is closed unless it is already in TCP_CLOSING state. The structure is freed and the client is left with no connection.

size_t EthernetClient::write ( const uint8_t *  buf,
size_t  size 
)
virtual

Writes a buffer to the connection.

Sends the data in chunks limited by the free space in the TCP send buffer, and forces each chunk out. Bytes queued before a TCP error are not reported.

Parameters
bufData to send.
sizeNumber of bytes in buf.
Returns
size if all bytes were queued, 0 on failure. Failure includes a client that is not connected or accepted, a NULL buf, size 0, and a TCP error.
