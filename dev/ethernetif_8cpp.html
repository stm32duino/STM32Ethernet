◆ ethernetif_set_link()

void ethernetif_set_link ( struct netif *  netif)

Poll the PHY and update the LwIP link state of the interface.

The link is set down when the PHY reports a link-change interrupt, and up when the PHY reports a linked state. With LWIP_IGMP, IGMP is started on the first link-up.

Parameters
netifThe LwIP network interface.

◆ ethernetif_update_config()

void ethernetif_update_config ( struct netif *  netif)

Apply the PHY auto-negotiation result to the MAC.

Restarts the MAC with the negotiated duplex and speed, or stops the MAC when the link is down. If auto-negotiation is disabled or has not completed, the configured duplex and speed are used. Calls ethernetif_notify_conn_changed() at the end. Call it when the link status changes.

Parameters
netifThe LwIP network interface.
