int DNSClient::getHostByName ( const char *  aHostname,
IPAddress &  aResult 
)

Resolves a host name to an IP address.

A numeric address string is converted directly. Otherwise the name is resolved through the DNS server set with begin().

Parameters
aHostnameHost name or numeric address to resolve.
aResultIPAddress that receives the resolved address.
Returns
1 on success. -2 if no valid DNS server is set. Otherwise the error code of the resolver: -1 on timeout, -2 if no address was found, or -4 on an LwIP error.
